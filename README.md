# AOSStudio SDK

AOSStudio SDK provides command-line Android™ development tools for Linux x86-64. The first release targets API 37.0 and includes the SDK platform, Build Tools, Platform Tools and Command-Line Tools. The SDK installs offline from a local SDK repository.
